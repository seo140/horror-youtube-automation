الخطوة الوحيدة المطلوبة قبل أن أستطيع نشر المشروع على Render:

1) افتح https://github.com/new وسجّل دخولك مجانًا.
2) اسم المستودع: horror-youtube-automation
3) اختر Public (هذا المستودع يحتوي كودًا فقط، لا يحتوي مفاتيح أو بيانات دخول).
4) اضغط Create repository.
5) من صفحة المستودع اختر uploading an existing file (أو Add file > Upload files).
6) فك ضغط ملف المشروع، ثم ارفع كل الملفات والمجلدات الموجودة بداخله، وليس ملف ZIP نفسه.
   تأكد أن Dockerfile وrender.yaml وserver.py تظهر في جذر المستودع.
7) اضغط Commit changes وأرسل رابط المستودع إلى ChatGPT.

بعد ذلك يمكن استخدام تكامل Render المتصل بالفعل لإنشاء خدمة خطة Free، بدون إضافة بطاقة أو تفعيل نشر تلقائي.
سيظل ENABLE_AUTOPUBLISH=false حتى اكتمال اختبار حقيقي وموافقتك على ربط قناة يوتيوب.
لا تضف GEMINI_API_KEY أو رموز Google OAuth إلى GitHub أو المحادثة؛ ستوضع كمتغيرات بيئة محمية على Render.

تنبيه: Render Free محدود بـ 0.1 CPU و512MB RAM، ولذلك نجاح الرندر الطويل بشكل مستقر غير مضمون.
